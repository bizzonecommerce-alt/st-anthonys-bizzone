# ST. Anthony's College Commerce Section Website

A bilingual Sinhala/English website with an admin login and content management panel.

## Features
- Responsive navy-and-gold professional design with CSS animations
- Sinhala / English language toggle
- Study resources with search and subject filter
- Events and announcements
- Profit / Loss calculator
- Admin login at `/admin`
- Admin can add, edit, and delete resources, events, and announcements
- SQLite database for persistent content storage
- Login rate limiting, HTTP security headers, secure production session cookies

## Requirements
- Node.js 20 or newer
- npm

## Run locally
1. Extract this ZIP.
2. Copy `.env.example` to a new file named `.env`.
3. Change `SESSION_SECRET` to a random secret of at least 32 characters.
4. Set a strong, unique `ADMIN_PASSWORD` and your desired `ADMIN_USERNAME`.
5. In this folder, run:
   ```bash
   npm install
   npm start
   ```
6. Open `http://localhost:3000` in your browser.
7. Admin panel: `http://localhost:3000/admin`

Never publish your `.env` file or share your admin password. Do not use the sample password.

## Deploy online using Render
1. Create a GitHub repository and upload the contents of this folder. Do not upload `.env` or `node_modules`.
2. Sign in to Render and choose **New + → Blueprint** (or create a Web Service from the repository).
3. Render can use `render.yaml` to configure the service and a persistent disk at `/var/data`.
4. In the Render service's Environment settings, set `ADMIN_USERNAME` and a strong, unique `ADMIN_PASSWORD`. `SESSION_SECRET` is generated by the Blueprint configuration.
5. Deploy and wait for the service URL. Visit that URL and add `/admin` for the dashboard.
6. Check `/api/health` to confirm the server is running.

**Hosting note:** a paid persistent disk may be required for SQLite data to survive redeploys on your chosen Render plan. Review current Render pricing and plan/disk rules before deploying. The website has not been published by this package; deployment requires your own hosting account and configuration.

## Before sharing with students
- Replace the sample announcement/resource/event entries with verified college content.
- Add only official resource links.
- Verify the college's preferred spelling, crest/logo, and contact details with the school.
- If the site will be used by many administrators or across multiple server instances, upgrade the session store and database architecture before scaling.
- Back up the SQLite database regularly.
